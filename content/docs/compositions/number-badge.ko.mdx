## 설치

```bash
bunx shadcn@latest add @ondo-ui/number-badge
```

`NumberBadge`와 함께 `badge`, `number-count`, 그리고 `@number-flow/react`
의존성이 설치됩니다.

## 사용법

```tsx
import { NumberBadge } from "@/components/compositions/number-badge"
```

```tsx
<NumberBadge value={5}>
  <Avatar>{/* … */}</Avatar>
</NumberBadge>
```

`NumberBadge`는 `children`(앵커)을 감싸 모서리에 카운트를 오버레이합니다. `max`를
넘는 `value`는 `99+`로, `value`가 `0`이면 `showZero`가 없는 한 뱃지를 숨깁니다.

## 예시

### 오버플로와 0 숨김

`max`(기본 `99`)를 넘는 `value`는 `99+`로 표시되고, `value`가 `0`이면 뱃지가
숨겨집니다. 두 경계를 넘겨보며 확인하세요.

<ComponentPreview name="number-badge-overflow">

```tsx
"use client"

import * as React from "react"
import { IconBell } from "@tabler/icons-react"

import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
import { NumberBadge } from "@/components/compositions/number-badge"
import { Button } from "@/components/ui/button"

export default function NumberBadgeOverflow() {
  const [value, setValue] = React.useState(3)

  return (
    <div className="flex flex-col items-center gap-4">
      <div className="flex items-center gap-8">
        <NumberBadge value={value}>
          <Avatar>
            <AvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
            <AvatarFallback>CN</AvatarFallback>
          </Avatar>
        </NumberBadge>
        <NumberBadge value={value}>
          <Button variant="outline" size="icon">
            <IconBell />
          </Button>
        </NumberBadge>
      </div>
      <div className="flex gap-2">
        <Button
          variant="outline"
          size="sm"
          onClick={() => setValue((v) => Math.max(0, v - 25))}
        >
          −25
        </Button>
        <Button
          variant="outline"
          size="sm"
          onClick={() => setValue((v) => v + 25)}
        >
          +25
        </Button>
      </div>
    </div>
  )
}
```

</ComponentPreview>

### 배리언트와 위치

`NumberBadge`는 [`Badge`](/docs/components/badge)의 모든 `variant`와 네 가지
`placement` 모서리를 지원합니다.

<ComponentPreview name="number-badge-variants">

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
import { NumberBadge } from "@/components/compositions/number-badge"

const variants = [
  "default",
  "secondary",
  "destructive",
  "outline",
  "ghost",
] as const

const placements = [
  "top-right",
  "top-left",
  "bottom-right",
  "bottom-left",
] as const

export default function NumberBadgeVariants() {
  return (
    <div className="flex flex-col items-center gap-10">
      <div className="flex flex-wrap items-start justify-center gap-6">
        {variants.map((variant) => (
          <div key={variant} className="flex flex-col items-center gap-2">
            <NumberBadge value={8} variant={variant}>
              <Avatar>
                <AvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
                <AvatarFallback>CN</AvatarFallback>
              </Avatar>
            </NumberBadge>
            <span className="text-xs text-muted-foreground capitalize">
              {variant}
            </span>
          </div>
        ))}
      </div>
      <div className="flex flex-wrap items-start justify-center gap-6">
        {placements.map((placement) => (
          <div key={placement} className="flex flex-col items-center gap-2">
            <NumberBadge value={8} placement={placement}>
              <Avatar>
                <AvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
                <AvatarFallback>CN</AvatarFallback>
              </Avatar>
            </NumberBadge>
            <span className="text-xs text-muted-foreground">{placement}</span>
          </div>
        ))}
      </div>
    </div>
  )
}
```

</ComponentPreview>

## API 참고

`NumberBadge`는 [`Badge`](/docs/components/badge)의 모든 prop을 받고(`children`
제외 — 앵커로 사용), 다음을 더합니다:

| Prop        | 타입                                                            | 기본값        | 설명                                              |
| ----------- | --------------------------------------------------------------- | ------------- | ------------------------------------------------- |
| `value`     | `number`                                                        | —             | 필수 카운트. `> max`면 `{max}+`.                  |
| `max`       | `number`                                                        | `99`          | 오버플로 상한.                                    |
| `showZero`  | `boolean`                                                       | `false`       | `value`가 `0`일 때 뱃지를 표시합니다.             |
| `placement` | `"top-right" \| "top-left" \| "bottom-right" \| "bottom-left"`  | `"top-right"` | `children` 위 모서리.                             |
| `variant`   | `Badge` 배리언트                                                | `"default"`   | `Badge`로 전달. |
| `children`  | `React.ReactNode`                                               | —             | 뱃지가 얹힐 앵커 엘리먼트.                         |
| `className` | `string`                                                        | —             | 오버레이된 `Badge`에 병합됩니다.                  |

## 기반 컴포넌트

`NumberBadge`가 조합하는 것:

- [`Badge`](/docs/components/badge) — 뱃지 셸과 배리언트.
- [`NumberCount`](/docs/components/number-count) — 안쪽의 애니메이션 카운트.

인라인(앵커 없는) 숫자 뱃지가 필요하면 [`Badge`](/docs/components/badge)와
[`NumberCount`](/docs/components/number-count)를 직접 조합하세요.
