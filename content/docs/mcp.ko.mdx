[shadcn MCP 서버](https://ui.shadcn.com/docs/mcp)는 `@ondo-ui` 레지스트리와 별도 설정 없이 바로 동작합니다. 한 번 구성해 두면 Claude Code, Cursor, GitHub Copilot 같은 AI 어시스턴트가 자연어 프롬프트만으로 레지스트리를 탐색하고, 컴포넌트 정보를 조회하고, 프로젝트에 설치할 수 있습니다.

MCP 서버는 [`https://ui.ondo.dou.so/r/registry.json`](https://ui.ondo.dou.so/r/registry.json)에서 서빙되는 레지스트리 인덱스를 통해 아이템을 발견합니다 — 레지스트리 쪽에서 추가로 활성화할 것은 없습니다.

## 레지스트리 등록

`components.json`의 `registries` 필드에 `@ondo-ui` 네임스페이스를 추가합니다. MCP 서버는 이 매핑을 읽어 레지스트리를 해석합니다. [설치](/docs/installation) 과정에서 이미 등록했다면 이 단계는 건너뛰세요:

```json title="components.json"
{
  "registries": {
    "@ondo-ui": "https://ui.ondo.dou.so/r/{name}.json"
  }
}
```

[Ondo CLI](/docs/cli)로 프로젝트를 초기화했다면 이 레지스트리 항목은
자동으로 추가됩니다. 각 클라이언트 설정도 Ondo CLI로 실행할 수 있습니다:

```bash
bunx --bun @dou.so/ondo-ui@latest mcp init --client claude
```

## 동작 방식

모든 레지스트리 아이템에는 description, npm `dependencies`, `registryDependencies`가 포함되어 있어 MCP 서버가 아이템의 용도를 설명하고 필요한 것을 한 번에 설치할 수 있습니다. 예를 들어 `@ondo-ui/alert-dialog`를 요청하면 `@ondo-ui/button`과 `@ondo-ui/utils`도 자동으로 함께 설치됩니다.

MCP는 레지스트리 접근을 제공합니다. 프로젝트를 인식하는 Base UI, 테마, 조합과 검토 지침도 필요하다면 [Ondo UI Skill](/docs/skills)을 추가하세요.

MCP 서버에 대한 자세한 내용은 [shadcn MCP 문서](https://ui.shadcn.com/docs/mcp)를 참고하세요.
