Ondo CLI는 Ondo 레지스트리와 framework 설정을 shadcn CLI 위에 연결합니다.

## 설치

전역 설치 없이 CLI를 실행합니다:

```bash
bunx --bun @dou.so/ondo-ui@latest --help
```

## 프로젝트 초기화

지원되는 framework를 초기화하고 Ondo 레지스트리를 설정합니다:

```bash
bunx --bun @dou.so/ondo-ui@latest init -t astro
```

Next.js, Vite, TanStack Start, React Router, Laravel, Astro를 지원합니다.
framework에 맞는 Ondo 테마를 설치하고 `components.json`에 `@ondo-ui`
레지스트리를 추가합니다.

기존 프로젝트는 `--cwd`와 함께 같은 명령을 사용할 수 있습니다:

```bash
bunx --bun @dou.so/ondo-ui@latest init -t vite --cwd ../my-vite-app
```

기존 앱에는 Tailwind CSS v4가 빌드에 연결되어 있고 `@/*` import alias가
동작해야 합니다 — shadcn preflight가 둘 다 검증하며, `init`이 대신 만들어
주지는 않습니다. 정확한 단계는 각 framework 가이드의 `Existing Project`
섹션을 참고하세요.

## 레지스트리 항목 추가

Components와 Compositions를 그룹으로 나누어 선택하는 메뉴를 엽니다:

```bash
bunx --bun @dou.so/ondo-ui@latest add
```

항목을 직접 지정하거나 선택 가능한 모든 항목을 설치합니다:

```bash
bunx --bun @dou.so/ondo-ui@latest add button empty-view
bunx --bun @dou.so/ondo-ui@latest add --all
bunx --bun @dou.so/ondo-ui@latest add -a
bunx --bun @dou.so/ondo-ui@latest add button --dry-run
```

`theme-provider` 같은 시스템 항목은 이름을 직접 지정하면 설치할 수 있지만
기본 메뉴에는 표시되지 않습니다.

### add 주요 옵션

| 옵션 | 용도 |
| --- | --- |
| `--all`, `-a` | 메뉴에 표시되는 모든 Component와 Composition을 설치합니다. |
| `--dry-run` | 프로젝트를 변경하지 않고 파일과 의존성을 미리 봅니다. |
| `--diff [path]` | 적용될 변경 사항을 보여줍니다. |
| `--view [path]` | 레지스트리 파일 내용을 적용하지 않고 보여줍니다. |
| `--cwd <path>` | 다른 프로젝트 디렉터리를 대상으로 실행합니다. |

레지스트리 namespace가 없는 이름은 `@ondo-ui/<name>`으로 해석합니다. 이미
registry 주소나 URL인 값은 그대로 전달합니다.

## 명령어 목록

프로젝트와 레지스트리 작업을 위해 shadcn 명령을 지원합니다:

`init`, `add`, `search`, `list`, `view`, `docs`, `diff`, `apply`, `info`,
`migrate`, `eject`, `mcp`, `preset`, `build`, `registry`.

`list`는 `search`의 별칭입니다. deprecated된 `diff`는 `add --diff`로
변환됩니다. 다른 프로젝트에서 실행하려면 `--cwd <path>`를 사용하세요.

예시:

```bash
bunx --bun @dou.so/ondo-ui@latest search @ondo-ui --query button
bunx --bun @dou.so/ondo-ui@latest view @ondo-ui/button
bunx --bun @dou.so/ondo-ui@latest mcp init --client claude
```

레지스트리 maintainer는 `build`와 `registry`로 레지스트리 파일을 만들고
검증할 수 있습니다.
