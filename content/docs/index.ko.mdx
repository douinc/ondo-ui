---

ondo-ui는 [shadcn 호환 레지스트리](https://ui.shadcn.com/docs/registry)로 배포되는 컴포넌트 모음입니다. 모든 컴포넌트는 [Base UI](https://base-ui.com) 프리미티브 위에 만들어졌고 [Tailwind CSS](https://tailwindcss.com)로 스타일링되어 있습니다.

npm으로 설치하는 컴포넌트 라이브러리가 **아닙니다**. 필요한 컴포넌트를 골라 shadcn CLI로 프로젝트에 복사해 오는 방식으로, 코드는 온전히 여러분의 것이 되어 자유롭게 수정할 수 있습니다.

## 원칙

- **열린 코드** — 모든 컴포넌트가 수정 가능한 일반 TypeScript 코드로 프로젝트에 들어옵니다.
- **기본 접근성** — 키보드와 스크린 리더를 지원하는 Base UI 프리미티브 기반입니다.
- **조합 가능** — 공통 API를 공유해 예측 가능하게 조합됩니다.
- **테마 지원** — oklch 색 공간의 CSS 변수만으로 스타일링됩니다.

## 시작하기

[설치](/docs/installation)에서 `@ondo-ui` 레지스트리를 프로젝트에 등록한 다음, [컴포넌트](/docs/components/button)를 살펴보세요.
