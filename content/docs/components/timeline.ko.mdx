### 진행 중인 단계 강조

`animate`는 지금 진행 중인 단계를 표시합니다 — `ping`은 인디케이터에서 고리가
퍼져 나가고, `pulse`는 은은하게 흐려졌다 진해집니다. 둘 다 `step === value`인
곳에서만 발동하므로 `.map()` 안에서 한 번만 지정하면 되고, `motion-safe`로
감싸져 있어 모션 줄이기를 켠 사용자에게는 정지한 인디케이터가 보입니다.

## 설치

```bash
bunx shadcn@latest add @ondo-ui/timeline
```

## 사용법

```tsx
import {
  Timeline,
  TimelineContent,
  TimelineDate,
  TimelineHeader,
  TimelineIndicator,
  TimelineItem,
  TimelineSeparator,
  TimelineTitle,
} from "@/components/ui/timeline"
```

```tsx
<Timeline>
  <TimelineItem step={1}>
    <TimelineHeader>
      <TimelineDate>2024년 3월</TimelineDate>
      <TimelineTitle>프로젝트 시작</TimelineTitle>
    </TimelineHeader>
    <TimelineIndicator />
    <TimelineSeparator />
    <TimelineContent>
      저장소와 초기 구조를 성공적으로 준비했습니다.
    </TimelineContent>
  </TimelineItem>
</Timeline>
```

## API 참고

### Timeline

타임라인의 루트 컴포넌트입니다.

| Prop            | 타입                         | 기본값       | 설명                                    |
| :-------------- | :--------------------------- | :----------- | :-------------------------------------- |
| `defaultValue`  | `number`                     | `1`          | 처음 활성화될 단계.                     |
| `value`         | `number`                     | -            | 현재 활성 단계(제어 모드).              |
| `onValueChange` | `(value: number) => void`    | -            | 활성 단계가 바뀔 때 호출되는 콜백.      |
| `orientation`   | `"horizontal" \| "vertical"` | `"vertical"` | 타임라인의 배치 방향.                   |
| `size`          | `"sm" \| "default" \| "lg"`  | `"default"`  | 인디케이터·아이콘·축 기하를 함께 조절.  |

`size`는 `--timeline-indicator`, `--timeline-icon`, `--timeline-rail`을
설정하고, 항목의 여백·인디케이터의 오프셋·연결선의 길이가 모두 여기서
파생됩니다. 그래서 크기를 바꾸면 축 전체가 한 덩어리로 움직이며, 점과 선이 따로
노는 상태가 생기지 않습니다.

<Callout>
  타임라인의 어떤 파트도 활성 단계를 바꾸지 않으므로, `onValueChange`는 직접
  세터를 호출할 때만 발화합니다. 실제로 쓰게 되는 것은 `value`와
  `defaultValue`입니다 — 어디까지 진행됐는지를 나타내고, `step`이 그 이하인
  항목이 완료 상태로 그려집니다.
</Callout>

### TimelineItem

타임라인의 단일 항목입니다.

| Prop   | 타입     | 기본값 | 설명                            |
| :----- | :------- | :----- | :------------------------------ |
| `step` | `number` | -      | **필수**. 이 항목의 단계 번호. |

| Prop        | 타입     | 기본값 | 설명                             |
| :---------- | :------- | :----- | :------------------------------- |
| `className` | `string` | -      | 날짜 레이블에 추가할 CSS 클래스. |

### TimelineTitle

항목의 제목입니다.

| Prop        | 타입     | 기본값 | 설명                        |
| :---------- | :------- | :----- | :-------------------------- |
| `className` | `string` | -      | 제목에 추가할 CSS 클래스.   |

### TimelineIndicator

항목의 시각적 표시(보통 점)입니다.

| Prop        | 타입                                                                        | 기본값      | 설명                                       |
| :---------- | :-------------------------------------------------------------------------- | :---------- | :----------------------------------------- |
| `variant`   | `"default" \| "muted" \| "info" \| "success" \| "warning" \| "destructive"` | `"default"` | 테마의 시맨틱 색상에서 인디케이터 색을 고릅니다. |
| `fill`      | `"outline" \| "solid"`                                                      | `"outline"` | 인디케이터를 테두리 링으로 그릴지 채운 원으로 그릴지 정합니다. |
| `animate`   | `"ping" \| "pulse"`                                                         | -           | 지금 진행 중인 단계를 강조합니다.          |
| `className` | `string`                                                                    | -           | 인디케이터에 추가할 CSS 클래스.            |

`variant`는 색을 정하고 `fill`은 그 색을 어떻게 입힐지 정합니다. 두 축이
독립적이라 어떤 색이든 링으로도 원으로도 그릴 수 있습니다. 인디케이터 안에
아이콘을 넣을 때는 아이콘이 올라앉을 배경이 필요하므로 `fill="solid"`를 쓰세요.

완료 여부는 어느 쪽을 골랐든 진하기를 더합니다 — 링은 옅은 테두리에서 진한
테두리로, 원은 은은한 배경에서 꽉 찬 배경으로 바뀝니다.

`animate`는 `step === value`인 단계에서만 발동합니다. 그래서 `.map()` 안에서 한
번만 지정해도 실제로 진행 중인 단계만 움직입니다. `motion-safe`로 감싸져 있어
모션 줄이기를 켠 사용자에게는 정지한 인디케이터가 보입니다.
