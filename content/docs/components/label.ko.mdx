<ComponentPreview name="label-demo">

```tsx
import { Checkbox } from "@/components/ui/checkbox"
import { Label } from "@/components/ui/label"

export default function LabelDemo() {
  return (
    <div className="flex gap-2">
      <Checkbox id="terms" />
      <Label htmlFor="terms">Accept terms and conditions</Label>
    </div>
  )
}
```

</ComponentPreview>

폼 필드의 경우 기본 레이블, 설명 및 오류 처리를 포함하는 [Field](/docs/components/field) 컴포넌트를 사용하세요.

## 설치

```bash
bunx shadcn@latest add @ondo-ui/label
```

## 사용법

```tsx
import { Label } from "@/components/ui/label"
```

```tsx
<Label htmlFor="email">Your email address</Label>
```

## API 참고

이 컴포넌트는 [Base UI Label](https://base-ui.com/react/components/label)을 감싸고 모든 props를 받습니다.
