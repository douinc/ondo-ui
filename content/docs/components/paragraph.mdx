<Callout>
  `Paragraph` is for application UI, the same as [`Heading`](/docs/components/heading).
  Rendered markdown and MDX already get their paragraph styles from the
  `typeset` layer, so you do not need this component inside prose.
</Callout>

## Installation

```bash
bunx shadcn@latest add @ondo-ui/paragraph
```

## Usage

```tsx
import { Paragraph } from "@/components/ui/paragraph"
```

```tsx
<Paragraph
  size="1 | 2 | 3 | 4 | 5 | 6"
  weight="normal | medium | semibold"
  tone="default | muted"
  wrap="normal | nowrap | balance | pretty"
>
  Paragraph
</Paragraph>
```

`size` picks a step on the body scale. Each step matches the `Heading` step
with the same number, so a heading and the paragraph under it can share one
number.

## Examples

### Sizes

`1` is the largest and `6` the smallest. `4` is the default and the one to
reach for in body copy.

<ComponentPreview name="paragraph-sizes">

```tsx
import { Paragraph } from "@/components/ui/paragraph"

export default function ParagraphSizes() {
  return (
    <div className="flex w-full max-w-md flex-col gap-5">
      <Paragraph size={1}>Size 1 — a lede paragraph under a hero heading.</Paragraph>
      <Paragraph size={2}>Size 2 — an intro paragraph for a section.</Paragraph>
      <Paragraph size={3}>Size 3 — a slightly larger body paragraph.</Paragraph>
      <Paragraph size={4}>Size 4 — the default body paragraph.</Paragraph>
      <Paragraph size={5}>Size 5 — supporting copy inside dense UI.</Paragraph>
      <Paragraph size={6}>Size 6 — captions, hints, and metadata.</Paragraph>
    </div>
  )
}
```

</ComponentPreview>

### Pairing with a heading

The two scales are numbered together. Passing the same `size` to `Heading` and
`Paragraph` keeps the title and its copy in proportion at every step.

<ComponentPreview name="paragraph-pairing">

```tsx
import { Heading } from "@/components/ui/heading"
import { Paragraph } from "@/components/ui/paragraph"

const sizes = [1, 2, 3, 4, 5, 6] as const

export default function ParagraphPairing() {
  return (
    <div className="flex w-full max-w-lg flex-col gap-8">
      {sizes.map((size) => (
        <div key={size} className="flex flex-col gap-2">
          <Heading level={2} size={size}>
            Ship a design system
          </Heading>
          <Paragraph size={size} tone="muted">
            Every heading size has a paragraph size with the same number, so a
            heading and the copy beneath it stay in proportion.
          </Paragraph>
        </div>
      ))}
    </div>
  )
}
```

</ComponentPreview>

### Tone and weight

`tone` switches between the foreground colour and the muted one. `weight` adds
emphasis without changing the size.

<ComponentPreview name="paragraph-tone">

```tsx
import { Paragraph } from "@/components/ui/paragraph"

export default function ParagraphTone() {
  return (
    <div className="flex w-full max-w-md flex-col gap-6">
      <Paragraph>The paragraph a reader is meant to read first.</Paragraph>
      <Paragraph tone="muted">
        Supporting copy that should stay in the background.
      </Paragraph>
      <Paragraph weight="medium">A paragraph carrying a little more weight.</Paragraph>
      <Paragraph weight="semibold">A lead-in line that introduces a list.</Paragraph>
    </div>
  )
}
```

</ComponentPreview>

### Wrap

`wrap` controls how the text breaks across lines and defaults to `pretty`,
which fills lines normally and only tidies the last one so a final word is not
left alone. `balance` evens out every line instead, which suits short blocks
rather than running copy.

<ComponentPreview name="paragraph-wrap">

```tsx
import { Paragraph } from "@/components/ui/paragraph"

export default function ParagraphWrap() {
  return (
    <div className="flex w-full max-w-[20rem] flex-col gap-6">
      <Paragraph>
        A paragraph wrapped with pretty fills every line normally and only
        tidies the last one, so no single word is left stranded.
      </Paragraph>
      <Paragraph wrap="balance">
        A paragraph wrapped with balance evens out every line, which suits
        short blocks such as a single callout sentence.
      </Paragraph>
    </div>
  )
}
```

</ComponentPreview>

### Custom element

Use the `render` prop when the markup needs a different element — a `span`
inside another paragraph, or a `figcaption` under an image — but you still want
the body scale.

<ComponentPreview name="paragraph-render">

```tsx
import { Paragraph } from "@/components/ui/paragraph"

export default function ParagraphRender() {
  return (
    <div className="flex w-full max-w-md flex-col gap-3">
      <Paragraph size={5} tone="muted" render={<span />}>
        Rendered as a span, for copy that sits inside another paragraph.
      </Paragraph>
      <Paragraph size={6} tone="muted" render={<figcaption />}>
        Rendered as a figcaption, for an image credit.
      </Paragraph>
    </div>
  )
}
```

</ComponentPreview>

## API reference

### Paragraph

Renders a `p` element styled from the body scale.

| Prop        | Type                                            | Default   |
| ----------- | ----------------------------------------------- | --------- |
| `size`      | `1 \| 2 \| 3 \| 4 \| 5 \| 6`                    | `4`       |
| `weight`    | `"normal" \| "medium" \| "semibold"`            | `normal`  |
| `tone`      | `"default" \| "muted"`                          | `default` |
| `wrap`      | `"normal" \| "nowrap" \| "balance" \| "pretty"` | `pretty`  |
| `render`    | `ReactElement \| (props, state) => ReactElement` | -         |
| `className` | `string`                                        | -         |

### Scale

| Size | Classes                                | Pairs with heading |
| ---- | -------------------------------------- | ------------------ |
| `1`  | `text-[1.25rem]/[1.6] tracking-[-0.006em]`   | `2.25rem` |
| `2`  | `text-[1.125rem]/[1.6] tracking-[-0.004em]`  | `1.75rem` |
| `3`  | `text-[1.0625rem]/[1.65] tracking-[-0.002em]` | `1.5rem` |
| `4`  | `text-[1rem]/[1.65]`                         | `1.375rem` |
| `5`  | `text-[0.9375rem]/[1.6] tracking-[0.002em]`  | `1.25rem` |
| `6`  | `text-[0.875rem]/[1.6] tracking-[0.004em]`   | `1.125rem` |

Every size also gets a colour from `tone`, a weight from `weight`, and a wrap
utility from `wrap` (`text-pretty` by default).
