## Composition

Use the following composition to build a `Pagination`:

```text
Pagination
└── PaginationContent
    ├── PaginationItem
    │   └── PaginationPrevious
    ├── PaginationItem
    │   └── PaginationLink
    ├── PaginationItem
    │   └── PaginationEllipsis
    └── PaginationItem
        └── PaginationNext
```

### Icons Only

Use just the previous and next buttons without page numbers. This is useful for data tables with a rows per page selector.

<ComponentPreview name="pagination-icons-only">

              <SelectItem value="50">50</SelectItem>

          <PaginationItem>
            <PaginationNext href="#" />
          </PaginationItem>
        </PaginationContent>
      </Pagination>
    </div>
  )

## API reference

The component exports the following sub-components:

- `Pagination` - The root container for pagination controls
- `PaginationContent` - A wrapper for pagination items
- `PaginationItem` - A container for individual pagination elements
- `PaginationLink` - A clickable pagination link with optional active state
- `PaginationPrevious` - A previous page button with icon
- `PaginationNext` - A next page button with icon
- `PaginationEllipsis` - An ellipsis indicator for skipped pages
