</ComponentPreview>

`Item` 구성 요소는 거의 모든 유형의 콘텐츠를 포함할 수 있는 간단한 flex 컨테이너입니다. 제목, 설명 및 작업을 표시하는 데 사용하세요. `ItemGroup` 구성 요소와 함께 그룹화하여 항목 목록을 만드세요.

## 설치

```bash
bunx shadcn@latest add @ondo-ui/item
```

## 사용법

```tsx showLineNumbers
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemMedia,
  ItemTitle,
} from "@/components/ui/item"
```

```tsx showLineNumbers
<Item>
  <ItemMedia variant="icon">
    <Icon />
  </ItemMedia>
  <ItemContent>
    <ItemTitle>Title</ItemTitle>
    <ItemDescription>Description</ItemDescription>
  </ItemContent>
  <ItemActions>
    <Button>Action</Button>
  </ItemActions>
</Item>
```

## Composition

`Item`을 구성하려면 다음 구성을 사용하세요:

```text
ItemGroup
└── Item
    ├── ItemHeader
    ├── ItemMedia
    ├── ItemContent
    │   ├── ItemTitle
    │   └── ItemDescription
    ├── ItemActions
    └── ItemFooter
```

  Item,
  ItemActions,
  ItemContent,

## API 참고

### Item

미디어, 제목, 설명 및 작업이 있는 콘텐츠를 표시하기 위한 기본 구성 요소입니다.

| Prop      | Type                                | Default     |
| --------- | ----------------------------------- | ----------- |
| `variant` | `"default" \| "outline" \| "muted"` | `"default"` |
| `size`    | `"default" \| "sm" \| "xs"`         | `"default"` |
| `render`  | `React.ReactElement`                |             |

### ItemGroup

관련 항목을 일관된 스타일로 함께 그룹화하는 컨테이너입니다.

```tsx
<ItemGroup>
  <Item />
  <Item />
</ItemGroup>
```

### ItemSeparator

그룹의 항목 사이의 구분선입니다.

```tsx
<ItemGroup>
  <Item />
  <ItemSeparator />
  <Item />
</ItemGroup>
```

### ItemMedia

`ItemMedia`를 사용하여 아이콘, 이미지 또는 아바타와 같은 미디어 콘텐츠를 표시합니다.

| Prop      | Type                             | Default     |
| --------- | -------------------------------- | ----------- |
| `variant` | `"default" \| "icon" \| "image"` | `"default"` |

```tsx
<ItemMedia variant="icon">
  <Icon />
</ItemMedia>
```

```tsx
<ItemMedia variant="image">
  <img src="..." alt="..." />
</ItemMedia>
```

### ItemContent

항목의 제목과 설명을 감쌉니다.

```tsx
<ItemContent>
  <ItemTitle>제목</ItemTitle>
  <ItemDescription>설명</ItemDescription>
</ItemContent>
```

### ItemTitle

항목의 제목을 표시합니다.

```tsx
<ItemTitle>항목 제목</ItemTitle>
```

### ItemDescription

항목의 설명을 표시합니다.

```tsx
<ItemDescription>항목 설명</ItemDescription>
```

### ItemActions

작업 버튼 또는 기타 상호 작용 요소의 컨테이너입니다.

```tsx
<ItemActions>
  <Button>작업</Button>
</ItemActions>
```

### ItemHeader

항목 콘텐츠 위에 헤더를 표시합니다.

```tsx
<Item>
  <ItemHeader>헤더</ItemHeader>
  <ItemContent>...</ItemContent>
</Item>
```

### ItemFooter

항목 콘텐츠 아래에 푸터를 표시합니다.

```tsx
<Item>
  <ItemContent>...</ItemContent>
  <ItemFooter>푸터</ItemFooter>
</Item>
```
