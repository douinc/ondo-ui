## Composition

`InputGroup`을 구성하려면 다음 구조를 사용하세요:

```text
InputGroup
├── InputGroupInput or InputGroupTextarea
├── InputGroupAddon
├── InputGroupButton
└── InputGroupText
```

## 정렬

`InputGroupAddon`의 `align` 속성을 사용하여 입력 필드와 관계없이 애드온을 배치하세요.

<Callout>
  적절한 포커스 관리를 위해 `InputGroupAddon`은 DOM에서 항상 `InputGroupInput` 또는 `InputGroupTextarea` 뒤에 배치되어야 합니다. `align` 속성을 사용하여 애드온을 시각적으로 배치하세요.
</Callout>

### inline-start

`align="inline-start"`를 사용하여 입력 필드의 시작 부분에 애드온을 배치하세요. 이것이 기본값입니다.

<ComponentPreview name="input-group-inline-start">

```tsx
import { IconSearch } from "@tabler/icons-react"

import {
  Field,
  FieldDescription,
  FieldLabel,
} from "@/components/ui/field"
import {
  InputGroup,
  InputGroupAddon,
  InputGroupInput,
} from "@/components/ui/input-group"

export default function InputGroupInlineStart() {
  return (
    <Field className="max-w-sm">
      <FieldLabel htmlFor="inline-start-input">Input</FieldLabel>
      <InputGroup>
        <InputGroupInput id="inline-start-input" placeholder="Search..." />
        <InputGroupAddon align="inline-start">
          <IconSearch className="text-muted-foreground" />
        </InputGroupAddon>
      </InputGroup>
      <FieldDescription>Icon positioned at the start.</FieldDescription>
    </Field>
  )
}
```

</ComponentPreview>

## 예시

### 크기

`size` prop으로 그룹 크기를 조절합니다. `xs`, `sm`, `default`, `lg`, `xl`, `2xl`을 지원합니다. 내부 컨트롤이 크기를 물려받아 입력의 높이와 글자가 그룹을 따라가고, `xl`과 `2xl`에서는 애드온 아이콘도 커집니다.

<ComponentPreview name="input-group-size">

```tsx
import { IconSearch } from "@tabler/icons-react"

import {
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupInput,
  InputGroupText,
} from "@/components/ui/input-group"
import { Kbd } from "@/components/ui/kbd"

const sizes = ["xs", "sm", "default", "lg", "xl", "2xl"] as const

export default function InputGroupSize() {
  return (
    <div className="flex w-full max-w-sm flex-col gap-4">
      {sizes.map((size) => (
        <InputGroup key={size} size={size}>
          <InputGroupAddon>
            <IconSearch />
          </InputGroupAddon>
          <InputGroupInput placeholder={`Size ${size}`} />
          <InputGroupAddon align="inline-end">
            <Kbd>/</Kbd>
          </InputGroupAddon>
        </InputGroup>
      ))}
      {sizes.map((size) => (
        <InputGroup key={`${size}-addons`} size={size}>
          <InputGroupAddon>
            <InputGroupText>https://</InputGroupText>
          </InputGroupAddon>
          <InputGroupInput placeholder="example.com" />
          <InputGroupAddon align="inline-end">
            <InputGroupButton>Copy</InputGroupButton>
          </InputGroupAddon>
        </InputGroup>
      ))}
    </div>
  )
}
```

</ComponentPreview>

## API 참고

### InputGroup

입력과 애드온을 래핑하는 주요 구성 요소입니다.

| Prop        | Type                                             | Default     |
| ----------- | ------------------------------------------------ | ----------- |
| `size`      | `"xs" \| "sm" \| "default" \| "lg" \| "xl" \| "2xl"` | `"default"` |
| `className` | `string`                                         |             |

```tsx
<InputGroup>
  <InputGroupInput />
  <InputGroupAddon />
</InputGroup>
```

### InputGroupAddon

입력 필드 옆에 아이콘, 텍스트, 버튼 또는 기타 콘텐츠를 표시합니다.

<Callout icon={<IconInfoCircle />} title="포커스 탐색">
  올바른 포커스 탐색을 위해 `InputGroupAddon` 구성 요소는 입력 뒤에 배치되어야 합니다. `align` 속성을 설정하여 애드온을 배치하세요.
</Callout>

| Prop        | Type                                                             | Default          |
| ----------- | ---------------------------------------------------------------- | ---------------- |
| `align`     | `"inline-start" \| "inline-end" \| "block-start" \| "block-end"` | `"inline-start"` |
| `className` | `string`                                                         |                  |

```tsx
<InputGroupAddon align="inline-end">
  <SearchIcon />
</InputGroupAddon>
```

**`<InputGroupInput />`의 경우 `inline-start` 또는 `inline-end` 정렬을 사용하세요. `<InputGroupTextarea />`의 경우 `block-start` 또는 `block-end` 정렬을 사용하세요.**

`InputGroupAddon` 구성 요소는 여러 `InputGroupButton` 구성 요소와 아이콘을 포함할 수 있습니다.

```tsx
<InputGroupAddon>
  <InputGroupButton>버튼</InputGroupButton>
  <InputGroupButton>버튼</InputGroupButton>
</InputGroupAddon>
```

### InputGroupButton

입력 그룹 내에 버튼을 표시합니다.

네 개의 이름 있는 크기는 upstream shadcn과 정확히 같습니다. 공식 문서의 예제를 그대로 복사해도 동일하게 렌더링됩니다.

`size`를 생략하면 버튼이 그룹에 스스로 맞춥니다 — 애드온 패딩을 피해 `xs` 그룹에선 20px부터 `2xl` 그룹에선 40px까지. `default` 그룹에서는 `xs`와 완전히 동일하므로 달라지는 것이 없고, 조절되는 단계는 upstream에 없는 그룹 크기를 위해서만 존재합니다. 높이만 조절하므로 아이콘 전용 버튼은 `icon-xs`나 `icon-sm`을 명시해야 합니다.

| Prop        | Type                                                                          | Default   |
| ----------- | ----------------------------------------------------------------------------- | --------- |
| `size`      | `"xs" \| "sm" \| "icon-xs" \| "icon-sm"`                                      | auto-fits the group |
| `variant`   | `"default" \| "outline" \| "secondary" \| "ghost" \| "info" \| "success" \| "warning" \| "destructive" \| "link"` | `"ghost"` |
| `className` | `string`                                                                      |           |

```tsx
<InputGroupButton>버튼</InputGroupButton>
<InputGroupButton size="icon-xs" aria-label="복사">
  <CopyIcon />
</InputGroupButton>
```

### InputGroupInput

입력 그룹을 구축할 때 `<Input />`을 대체합니다. 이 구성 요소는 입력 그룹 스타일이 미리 적용되어 있으며 자동 포커스 상태 처리를 위해 통합 `data-slot="input-group-control"`을 사용합니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

다른 모든 속성은 기본 `<Input />` 구성 요소로 전달됩니다.

```tsx
<InputGroup>
  <InputGroupInput placeholder="텍스트 입력..." />
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
</InputGroup>
```

### InputGroupTextarea

입력 그룹을 구축할 때 `<Textarea />`를 대체합니다. 이 구성 요소는 텍스트 영역 그룹 스타일이 미리 적용되어 있으며 자동 포커스 상태 처리를 위해 통합 `data-slot="input-group-control"`을 사용합니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

다른 모든 속성은 기본 `<Textarea />` 구성 요소로 전달됩니다.

```tsx
<InputGroup>
  <InputGroupTextarea placeholder="메시지 입력..." />
  <InputGroupAddon align="block-end">
    <InputGroupButton>보내기</InputGroupButton>
  </InputGroupAddon>
</InputGroup>
```
