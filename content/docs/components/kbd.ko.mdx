## 설치

```bash
bunx shadcn@latest add @ondo-ui/kbd
```

## 사용법

```tsx
import { Kbd } from "@/components/ui/kbd"
```

```tsx
<Kbd>Ctrl</Kbd>
```

## Composition

`Kbd`와 `KbdGroup`을 구성하려면 다음 구조를 사용하세요:

```text
Kbd
KbdGroup
├── Kbd
└── Kbd
```

## 예시

### Group

`KbdGroup` 컴포넌트를 사용하여 키보드 키들을 함께 그룹화합니다.

<ComponentPreview name="kbd-group">

```tsx
import { Kbd, KbdGroup as KbdGroupComponent } from "@/components/ui/kbd"

export default function KbdGroup() {
  return (
    <div className="flex flex-col items-center gap-4">
      <p className="text-sm text-muted-foreground">
        Use{" "}
        <KbdGroupComponent>
          <Kbd>Ctrl + B</Kbd>
          <Kbd>Ctrl + K</Kbd>
        </KbdGroupComponent>{" "}
        to open the command palette
      </p>
    </div>
  )
}
```

</ComponentPreview>

### Button

`Button` 컴포넌트 내에서 `Kbd` 컴포넌트를 사용하여 버튼 내에 키보드 키를 표시합니다.

<ComponentPreview name="kbd-button">

```tsx
import { Button } from "@/components/ui/button"
import { Kbd } from "@/components/ui/kbd"

export default function KbdButton() {
  return (
    <Button variant="outline">
      Accept{" "}
      <Kbd data-icon="inline-end" className="translate-x-0.5">
        ⏎
      </Kbd>
    </Button>
  )
}
```

</ComponentPreview>

### Tooltip

`Tooltip` 컴포넌트 내에서 `Kbd` 컴포넌트를 사용하여 키보드 키가 있는 툴팁을 표시할 수 있습니다.

<ComponentPreview name="kbd-tooltip">

```tsx
import { Button } from "@/components/ui/button"
import { ButtonGroup } from "@/components/ui/button-group"
import { Kbd, KbdGroup } from "@/components/ui/kbd"
import {
  Tooltip,
  TooltipContent,
  TooltipTrigger,
} from "@/components/ui/tooltip"

export default function KbdTooltip() {
  return (
    <div className="flex flex-wrap gap-4">
      <ButtonGroup>
        <Tooltip>
          <TooltipTrigger render={<Button variant="outline" />}>
            Save
          </TooltipTrigger>
          <TooltipContent>
            Save Changes <Kbd>S</Kbd>
          </TooltipContent>
        </Tooltip>
        <Tooltip>
          <TooltipTrigger render={<Button variant="outline" />}>
            Print
          </TooltipTrigger>
          <TooltipContent>
            Print Document{" "}
            <KbdGroup>
              <Kbd>Ctrl</Kbd>
              <Kbd>P</Kbd>
            </KbdGroup>
          </TooltipContent>
        </Tooltip>
      </ButtonGroup>
    </div>
  )
}
```

</ComponentPreview>

### Input Group

`InputGroupAddon` 컴포넌트 내에서 `Kbd` 컴포넌트를 사용하여 입력 그룹 내에 키보드 키를 표시할 수 있습니다.

<ComponentPreview name="kbd-input-group">

```tsx
import { IconSearch } from "@tabler/icons-react"

import {
  InputGroup,
  InputGroupAddon,
  InputGroupInput,
} from "@/components/ui/input-group"
import { Kbd } from "@/components/ui/kbd"

export default function KbdInputGroup() {
  return (
    <div className="flex w-full max-w-xs flex-col gap-6">
      <InputGroup>
        <InputGroupInput placeholder="Search..." />
        <InputGroupAddon>
          <IconSearch />
        </InputGroupAddon>
        <InputGroupAddon align="inline-end">
          <Kbd>⌘</Kbd>
          <Kbd>K</Kbd>
        </InputGroupAddon>
      </InputGroup>
    </div>
  )
}
```

</ComponentPreview>

## API 참고

### Kbd

`Kbd` 컴포넌트를 사용하여 키보드 키를 표시합니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | ``      |

```tsx
<Kbd>Ctrl</Kbd>
```

### KbdGroup

`KbdGroup` 컴포넌트를 사용하여 `Kbd` 컴포넌트들을 함께 그룹화합니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | ``      |

```tsx
<KbdGroup>
  <Kbd>Ctrl</Kbd>
  <Kbd>B</Kbd>
</KbdGroup>
```
