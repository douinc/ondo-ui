<ComponentPreview name="progress-demo">

```tsx
"use client"

import * as React from "react"

import { Progress } from "@/components/ui/progress"

export default function ProgressDemo() {
  const [progress, setProgress] = React.useState(13)

  React.useEffect(() => {
    const timer = setTimeout(() => setProgress(66), 500)
    return () => clearTimeout(timer)
  }, [])

  return <Progress value={progress} className="w-[60%]" />
}
```

</ComponentPreview>

<Callout>
  이 영역은 네 컴포넌트가 나눠 맡습니다. `Progress`와

  [`Meter`](/docs/components/meter)와
  [`MeterRing`](/docs/components/meter-ring)은 그 자체로 하나의 상태인 값을

## 예시

### Label

레이블과 값을 표시하려면 `ProgressLabel`과 `ProgressValue`를 사용하세요.

<ComponentPreview name="progress-label">

```tsx
import {
  Progress,
  ProgressLabel as ProgressLabelComponent,
  ProgressValue,
} from "@/components/ui/progress"

export default function ProgressLabel() {
  return (
    <Progress value={56} className="w-full max-w-sm">
      <ProgressLabelComponent>Upload progress</ProgressLabelComponent>
      <ProgressValue />
    </Progress>
  )
}
```

</ComponentPreview>

### Variants

`variant`는 테마의 시맨틱 색상에서 막대 색을 고릅니다. 작업이 멈췄는지, 다시
시도 중인지, 깔끔하게 끝났는지를 알릴 때 유용합니다. 막대는 `bg-current`로
칠해지므로 `className`의 텍스트 색상 유틸리티로도 바꿀 수 있습니다.

<ComponentPreview name="progress-variants">

```tsx
import {
  Progress,
  ProgressLabel,
  ProgressValue,
} from "@/components/ui/progress"

export default function ProgressVariants() {
  return (
    <div className="flex w-full max-w-sm flex-col gap-5">
      <Progress value={24} variant="info">
        <ProgressLabel>업로드 중</ProgressLabel>
        <ProgressValue />
      </Progress>
      <Progress value={62} variant="warning">
        <ProgressLabel>재시도 중</ProgressLabel>
        <ProgressValue />
      </Progress>
      <Progress value={100} variant="success">
        <ProgressLabel>완료</ProgressLabel>
        <ProgressValue />
      </Progress>
    </div>
  )
}
```

</ComponentPreview>

### Controlled

슬라이더로 조절할 수 있는 프로그레스 바입니다.

<ComponentPreview name="progress-controlled">

```tsx
"use client"

import * as React from "react"

import { Progress } from "@/components/ui/progress"
import { Slider } from "@/components/ui/slider"

export default function ProgressControlled() {
  const [value, setValue] = React.useState(50)

  return (
    <div className="flex w-full max-w-sm flex-col gap-4">
      <Progress value={value} className="w-full" />
      <Slider
        value={value}
        onValueChange={(value) => setValue(value as number)}
        min={0}
        max={100}
        step={1}
      />
    </div>
  )
}
```

</ComponentPreview>

### An animated value

`ProgressValue`는 렌더 함수를 받으므로, 값을
[`NumberCount`](/docs/components/number-count)에 넘기면 숫자가 툭 바뀌지 않고
굴러갑니다. Base UI가 이 부분을 `aria-hidden`으로 표시하므로 애니메이션은
순수하게 시각적이고 — 읽히는 값은 여전히 루트에서 옵니다 — `NumberCount`는
`prefers-reduced-motion`을 존중합니다.

렌더 함수는 *서식이 적용된 문자열*과 원본 숫자만 받기 때문에, 서식은
`Progress`에서 상속되지 않고 `NumberCount`에 다시 지정해야 합니다. 이때 둘을
헷갈리지 마세요. 0~100 스케일에는 `suffix="%"`를 쓰고,
`format={{ style: "percent" }}`는 값이 이미 0~1 분수일 때 쓰는 것이라 여기서는
`2400%`로 읽힙니다.

함수 prop이므로, 이를 넘기는 컴포넌트는 클라이언트 컴포넌트여야 합니다.

<ComponentPreview name="progress-number-count">

```tsx
"use client"

import * as React from "react"

import { Button } from "@/components/ui/button"
import { NumberCount } from "@/components/ui/number-count"
import {
  Progress,
  ProgressLabel,
  ProgressValue,
} from "@/components/ui/progress"

export default function ProgressNumberCount() {
  const [value, setValue] = React.useState(24)

  return (
    <div className="flex w-full max-w-sm flex-col gap-4">
      <Progress value={value} variant="info">
        <ProgressLabel>업로드 중</ProgressLabel>
        <ProgressValue>
          {(_, v) => (v == null ? null : <NumberCount value={v} suffix="%" />)}
        </ProgressValue>
      </Progress>
      <div className="flex gap-2">
        <Button
          size="sm"
          variant="outline"
          onClick={() => setValue((v) => Math.max(0, v - 17))}
        >
          −17
        </Button>
        <Button
          size="sm"
          variant="outline"
          onClick={() => setValue((v) => Math.min(100, v + 17))}
        >
          +17
        </Button>
      </div>
    </div>
  )
}
```

</ComponentPreview>

값이 `null`일 때 `null`을 반환하면 진행률을 알 수 없는 막대의 값이 비어 있게
되는데, 이는 Base UI의 기본 동작과 같습니다.

## API 참고

| Prop | 타입 | 기본값 |
| --- | --- | --- |
| `value` | `number \| null` | – |
| `variant` | `"default" \| "info" \| "success" \| "warning" \| "destructive"` | `"default"` |

이 컴포넌트는 [Base UI Progress](https://base-ui.com/react/components/progress)를 감싸며 해당 컴포넌트의 모든 prop을 받습니다.

`value={null}`을 넘기면 진행률을 알 수 없는 상태가 됩니다. 같은 컴포넌트의 원형
형태는 [`ProgressRing`](/docs/components/progress-ring)을 보세요.
