## Composition

### Field

하나의 컨트롤에 레이블, 도움말 텍스트, 검증 기능을 제공합니다.

```text
Field
├── FieldLabel
├── Input / Textarea / Switch / Select
├── FieldDescription
└── FieldError
```

### FieldGroup

관련된 필드들을 하나의 그룹으로 묶습니다. 필요한 경우 FieldSeparator를 사용하여 섹션을 분할할 수 있습니다.

```text
FieldGroup
├── Field
│   ├── FieldLabel
│   ├── Input / Textarea / Switch / Select
│   ├── FieldDescription
│   └── FieldError
├── FieldSeparator
└── Field
    ├── FieldLabel
    └── Input / Textarea / Switch / Select
```

### FieldSet

레이블과 설명을 포함하는 의미론적 그룹화로, 일반적으로 FieldGroup을 포함합니다.

```text
FieldSet
├── FieldLegend
├── FieldDescription
└── FieldGroup
    ├── Field
    │   ├── FieldLabel
    │   ├── Input / Textarea / Switch / Select
    │   ├── FieldDescription
    │   └── FieldError
    └── Field
        ├── FieldLabel
        └── Input / Textarea / Switch / Select
```

## Anatomy

Field 제품군은 접근성 있는 폼 작성을 위해 설계되었습니다. 일반적인 필드 구조는 다음과 같습니다:

```tsx showLineNumbers
<Field>
  <FieldLabel htmlFor="input-id">Label</FieldLabel>
  {/* Input, Select, Switch, etc. */}
  <FieldDescription>Optional helper text.</FieldDescription>
  <FieldError>Validation message.</FieldError>
</Field>
```

- Field는 단일 필드의 핵심 래퍼입니다.
- FieldContent는 레이블과 설명을 그룹화하는 플렉스 열입니다. 설명이 없으면 필수가 아닙니다.
- 관련 필드는 FieldGroup으로 래핑하고, 의미론적 그룹화를 위해 FieldSet과 FieldLegend를 사용하세요.

## 간격

간격은 컴포넌트가 정합니다. 필드마다 따로 지정하지 않아도 폼 전체가 맞아떨어집니다.

| 대상 | 값 | 정하는 곳 |
| ---- | -- | --------- |
| 레이블과 그 아래 컨트롤 | `8px` | `Field` |
| 체크박스·라디오와 그 레이블 | `8px` | `orientation="horizontal"`인 `Field` |
| `FieldContent` 안의 레이블과 설명 | `4px` | `FieldContent` |
| 그룹 안의 필드와 필드 | `20px` | `FieldGroup` |
| 그룹 안의 선택 항목 줄 사이 | `12px` | 자식이 모두 가로 필드일 때의 `FieldGroup` |
| 묶음 제목과 그 아래 내용 | `14px` | `FieldLegend` |

두 가지 규칙은 prop이 아니라 필드가 무엇을 담고 있는지를 보고 적용됩니다.

- 자식이 *전부* 가로 필드인 `FieldGroup`은 선택 목록으로 보고 `12px`로 좁힙니다.
  필드 세트나 구분선, 세로 필드가 섞여 있으면 `20px`을 유지합니다.
- 자기 체크박스나 라디오 바로 뒤에 오는 `FieldLabel`은 필드 이름이 아니라 선택
  항목이므로 medium이 아닌 본문 굵기를 씁니다.

세로로 쌓인 `FieldLabel`과 `FieldDescription`은 `3px` 들여씁니다. 컨트롤의 둥근
모서리 바깥으로 삐져나와 보이지 않고, 컨트롤 안쪽 글자와 시작점이 맞습니다. 가로
필드는 들여쓰지 않으므로 레이블이 옆의 체크박스와 계속 정렬됩니다.

## Responsive Layout

- **수직 필드**: 기본 방향은 레이블, 컨트롤, 도움말 텍스트를 스택하며, 모바일 우선 레이아웃에 이상적입니다.
- **수평 필드**: Field에 orientation="horizontal"을 설정하여 레이블과 컨트롤을 나란히 정렬합니다. 설명을 정렬 상태로 유지하려면 FieldContent와 함께 사용하세요.
- **반응형 필드**: orientation="responsive"를 설정하여 컨테이너 인식 부모 내에서 자동 열 레이아웃을 활용합니다. FieldGroup에 @container/field-group 클래스를 적용하여 특정 중단점에서 방향을 전환합니다.

```tsx
import { Button } from "@/components/ui/button"
import {
  Field,
  FieldContent,
  FieldDescription,
  FieldGroup,
  FieldLabel,
  FieldLegend,
  FieldSet,
} from "@/components/ui/field"
import { Input } from "@/components/ui/input"

export function FieldResponsive() {
  return (
    <div className="w-full max-w-lg">
      <form>
        <FieldSet>
          <FieldLegend>Profile</FieldLegend>
          <FieldDescription>Fill in your profile information.</FieldDescription>
          <FieldGroup>
            <Field orientation="responsive">
              <FieldContent>
                <FieldLabel htmlFor="name">Name</FieldLabel>
                <FieldDescription>
                  Provide your full name for identification
                </FieldDescription>
              </FieldContent>
              <Input id="name" placeholder="Evil Rabbit" required />
            </Field>
            <Field orientation="responsive">
              <Button type="submit">Submit</Button>
              <Button type="button" variant="outline">
                Cancel
              </Button>
            </Field>
          </FieldGroup>
        </FieldSet>
      </form>
    </div>
  )
}
```

## Validation and Errors

- Field에 data-invalid를 추가하여 전체 블록을 오류 상태로 전환합니다.
- 보조 기술을 위해 입력 자체에 aria-invalid를 추가합니다.
- FieldError를 컨트롤 직후 또는 FieldContent 내에 렌더링하여 오류 메시지를 필드와 정렬된 상태로 유지합니다.

```tsx showLineNumbers /data-invalid/ /aria-invalid/
<Field data-invalid>
  <FieldLabel htmlFor="email">Email</FieldLabel>
  <Input id="email" type="email" aria-invalid />
  <FieldError>Enter a valid email address.</FieldError>
</Field>
```

## Accessibility

- FieldSet과 FieldLegend는 키보드 및 보조 기술 사용자를 위해 관련 컨트롤을 그룹화합니다.
- Field는 role="group"을 출력하므로 중첩된 컨트롤은 FieldLabel 및 FieldLegend에서 레이블을 상속합니다.
- FieldSeparator는 신중하게 적용하여 스크린 리더 사용자가 명확한 섹션 경계를 만나도록 하세요.

## API 참고

### FieldSet

간격 사전 설정이 있는 의미론적 fieldset을 렌더링하는 컨테이너입니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldSet>
  <FieldLegend>Delivery</FieldLegend>
  <FieldGroup>{/* Fields */}</FieldGroup>
</FieldSet>
```

### FieldLegend

FieldSet의 범례 요소입니다. label 변형으로 전환하여 레이블 크기 조정과 정렬을 맞춥니다.

| Prop        | Type                  | Default    |
| ----------- | --------------------- | ---------- |
| `variant`   | `"legend" \| "label"` | `"legend"` |
| `className` | `string`              |            |

```tsx
<FieldLegend variant="label">Notification Preferences</FieldLegend>
```

FieldLegend에는 legend와 label이라는 두 가지 변형이 있습니다. label 변형은 레이블 크기 조정과 정렬을 적용합니다. 중첩된 FieldSet이 있을 때 유용합니다.

### FieldGroup

Field 컴포넌트를 스택하고 반응형 방향을 위한 컨테이너 쿼리를 활성화하는 레이아웃 래퍼입니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldGroup className="@container/field-group flex flex-col gap-6">
  <Field>{/* ... */}</Field>
  <Field>{/* ... */}</Field>
</FieldGroup>
```

### Field

단일 필드의 핵심 래퍼입니다. 방향 제어, 잘못된 상태 스타일, 간격을 제공합니다.

| Prop           | Type                                         | Default      |
| -------------- | -------------------------------------------- | ------------ |
| `orientation`  | `"vertical" \| "horizontal" \| "responsive"` | `"vertical"` |
| `className`    | `string`                                     |              |
| `data-invalid` | `boolean`                                    |              |

```tsx
<Field orientation="horizontal">
  <FieldLabel htmlFor="remember">Remember me</FieldLabel>
  <Switch id="remember" />
</Field>
```

### FieldContent

레이블이 컨트롤 옆에 있을 때 컨트롤과 설명을 그룹화하는 플렉스 열입니다. 설명이 없으면 필수가 아닙니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<Field>
  <Checkbox id="notifications" />
  <FieldContent>
    <FieldLabel htmlFor="notifications">Notifications</FieldLabel>
    <FieldDescription>Email, SMS, and push options.</FieldDescription>
  </FieldContent>
</Field>
```

### FieldLabel

직접 입력 및 중첩된 Field 자식 모두를 위해 스타일이 지정된 레이블입니다.

| Prop        | Type      | Default |
| ----------- | --------- | ------- |
| `className` | `string`  |         |
| `asChild`   | `boolean` | `false` |

```tsx
<FieldLabel htmlFor="email">Email</FieldLabel>
```

### FieldTitle

FieldContent 내에 레이블 스타일의 제목을 렌더링합니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldContent>
  <FieldTitle>Enable Touch ID</FieldTitle>
  <FieldDescription>Unlock your device faster.</FieldDescription>
</FieldContent>
```

### FieldDescription

수평 레이아웃에서 긴 줄을 자동으로 조정하는 도움말 텍스트 슬롯입니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldDescription>We never share your email with anyone.</FieldDescription>
```

### FieldSeparator

FieldGroup 내 섹션을 분할하는 시각적 구분선입니다. 선택적 인라인 콘텐츠를 허용합니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldSeparator>Or continue with</FieldSeparator>
```

### FieldError

접근성 있는 오류 컨테이너로, 자식 또는 errors 배열(예: react-hook-form에서)을 허용합니다.

| Prop        | Type                                       | Default |
| ----------- | ------------------------------------------ | ------- |
| `errors`    | `Array<{ message?: string } \| undefined>` |         |
| `className` | `string`                                   |         |

```tsx
<FieldError errors={errors.username} />
```

errors 배열에 여러 메시지가 포함되면 컴포넌트가 자동으로 목록을 렌더링합니다.

FieldError는 또한 Zod, Valibot, ArkType을 포함한 Standard Schema를 구현하는 모든 검증자에 의해 생성된 문제도 허용합니다. 스키마 결과의 issues 배열을 직접 전달하여 라이브러리 전반에서 통합된 오류 목록을 렌더링합니다.
