## Composition

`Pagination`을 구성하려면 다음 구조를 사용하세요:

```text
Pagination
└── PaginationContent
    ├── PaginationItem
    │   └── PaginationPrevious
    ├── PaginationItem
    │   └── PaginationLink
    ├── PaginationItem
    │   └── PaginationEllipsis
    └── PaginationItem
        └── PaginationNext
```

<ComponentPreview name="pagination-simple">

```tsx
        <PaginationItem>
          <PaginationLink href="#">1</PaginationLink>

        <PaginationItem>

            2
          </PaginationLink>
        </PaginationItem>

        </PaginationItem>
        <PaginationItem>

          <PaginationLink href="#">5</PaginationLink>

      </PaginationContent>
```

### Icons Only

페이지 번호 없이 이전/다음 버튼만 표시합니다. 이는 행 개수 선택기가 있는 데이터 테이블에 유용합니다.

```tsx
  PaginationContent,
  PaginationItem,

  PaginationPrevious,

  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectTrigger,
  SelectValue,

  return (
    <div className="flex items-center justify-between gap-4">
      <Field orientation="horizontal" className="w-fit">
        <FieldLabel htmlFor="select-rows-per-page">페이지당 행 수</FieldLabel>
        <Select defaultValue="25">
          <SelectTrigger className="w-20" id="select-rows-per-page">
            <SelectValue />
          </SelectTrigger>
          <SelectContent align="start">
            <SelectGroup>
              <SelectItem value="10">10</SelectItem>
              <SelectItem value="25">25</SelectItem>
              <SelectItem value="50">50</SelectItem>
              <SelectItem value="100">100</SelectItem>
            </SelectGroup>
          </SelectContent>
        </Select>
      </Field>
      <Pagination className="mx-0 w-auto">
        <PaginationContent>
          <PaginationItem>
            <PaginationPrevious href="#" />
          </PaginationItem>
          <PaginationItem>
            <PaginationNext href="#" />
          </PaginationItem>
        </PaginationContent>
      </Pagination>
    </div>
  )
}
```

</ComponentPreview>

## API 참고

이 컴포넌트는 다음의 서브 컴포넌트를 내보냅니다:

- `Pagination` - 페이지 네비게이션 컨트롤을 위한 루트 컨테이너
- `PaginationContent` - 페이지 네비게이션 항목을 감싸는 래퍼
- `PaginationItem` - 개별 페이지 네비게이션 요소를 위한 컨테이너
- `PaginationLink` - 활성 상태를 선택적으로 지원하는 클릭 가능한 페이지 링크
- `PaginationPrevious` - 아이콘이 있는 이전 페이지 버튼
- `PaginationNext` - 아이콘이 있는 다음 페이지 버튼
- `PaginationEllipsis` - 건너뛴 페이지를 나타내는 줄임표 표시
