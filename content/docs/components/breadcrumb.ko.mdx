## Composition

`Breadcrumb`를 빌드하려면 다음 조합을 사용하세요:

```text
Breadcrumb
└── BreadcrumbList
    ├── BreadcrumbItem
    │   └── BreadcrumbLink
    ├── BreadcrumbSeparator
    ├── BreadcrumbItem
    │   └── BreadcrumbLink
    ├── BreadcrumbSeparator
    └── BreadcrumbItem
        └── BreadcrumbPage
```

## 예시

### Basic

홈 링크와 컴포넌트 링크가 있는 기본 breadcrumb입니다.

<ComponentPreview name="breadcrumb-basic">

```tsx

  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@/components/ui/breadcrumb"

export default function BreadcrumbBasic() {
  return (
    <Breadcrumb>
      <BreadcrumbList>
        <BreadcrumbItem>
          <BreadcrumbLink href="#">Home</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbLink href="#">Components</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbPage>Breadcrumb</BreadcrumbPage>
        </BreadcrumbItem>
      </BreadcrumbList>
    </Breadcrumb>
  )
}
```

</ComponentPreview>

## API 참고

### Breadcrumb

`Breadcrumb` 컴포넌트는 모든 breadcrumb 컴포넌트를 래핑하는 루트 네비게이션 요소입니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### BreadcrumbList

`BreadcrumbList` 컴포넌트는 breadcrumb 항목의 정렬된 목록을 표시합니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### BreadcrumbItem

`BreadcrumbItem` 컴포넌트는 개별 breadcrumb 항목을 래핑합니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### BreadcrumbLink

`BreadcrumbLink` 컴포넌트는 breadcrumb에서 클릭 가능한 링크를 표시합니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### BreadcrumbPage

`BreadcrumbPage` 컴포넌트는 breadcrumb에서 현재 페이지를 표시합니다(클릭할 수 없음).

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### BreadcrumbSeparator

`BreadcrumbSeparator` 컴포넌트는 breadcrumb 항목 사이의 구분기호를 표시합니다. 기본 구분기호를 재정의하기 위해 커스텀 자식을 전달할 수 있습니다.

| Prop        | Type              | Default |
| ----------- | ----------------- | ------- |
| `children`  | `React.ReactNode` | -       |
| `className` | `string`          | -       |

### BreadcrumbEllipsis

`BreadcrumbEllipsis` 컴포넌트는 축소된 breadcrumb 항목에 대한 줄임표 표시기를 표시합니다.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | -       |
