```text

├── CardHeader

```

### Spacing

`size` prop 외에도 `--card-spacing` CSS 변수를 사용하여 섹션 간의 간격과 카드 부분의 삽입을 제어할 수 있습니다.

<ComponentPreview name="card-spacing">

```tsx
"use client"

import * as React from "react"

import { Button } from "@/components/ui/button"
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"
import {
  ToggleGroup,
  ToggleGroupItem,
} from "@/components/ui/toggle-group"

const spacingOptions = [
  {
    className: "[--card-spacing:--spacing(4)]",
    label: "16px",
    value: "4",
  },
  {
    className: "[--card-spacing:--spacing(5)]",
    label: "20px",
    value: "5",
  },
  {
    className: "[--card-spacing:--spacing(6)]",
    label: "24px",
    value: "6",
  },
  {
    className: "[--card-spacing:--spacing(8)]",
    label: "32px",
    value: "8",
  },
]

export default function CardSpacing() {
  const [spacing, setSpacing] = React.useState("4")
  const selectedSpacing = spacingOptions.find(
    (option) => option.value === spacing
  )

  return (
    <div className="mx-auto grid w-full max-w-sm gap-4">
      <ToggleGroup
        value={[spacing]}
        onValueChange={(value) => {
          if (value[0]) {
            setSpacing(value[0])
          }
        }}
        variant="outline"
        size="sm"
        className="justify-center"
      >
        {spacingOptions.map((option) => (
          <ToggleGroupItem key={option.value} value={option.value}>
            {option.label}
          </ToggleGroupItem>
        ))}
      </ToggleGroup>
      <Card className={selectedSpacing?.className}>
        <CardHeader>
          <CardTitle>계정에 로그인</CardTitle>
          <CardDescription>
            아래에 이메일을 입력하여 계정에 로그인하세요
          </CardDescription>
          <CardAction>
            <Button variant="link">가입하기</Button>
          </CardAction>
        </CardHeader>
        <CardContent>
          <form>
            <div className="flex flex-col gap-6">
              <div className="grid gap-2">
                <Label htmlFor="email-spacing">이메일</Label>
                <Input
                  id="email-spacing"
                  type="email"
                  placeholder="m@example.com"
                  required
                />
              </div>
              <div className="grid gap-2">
                <div className="flex items-center">
                  <Label htmlFor="password-spacing">비밀번호</Label>
                  <a
                    href="#"
                    className="ml-auto inline-block text-sm underline-offset-4 hover:underline"
                  >
                    비밀번호를 잊으셨나요?
                  </a>
                </div>
                <Input id="password-spacing" type="password" required />
              </div>
            </div>
          </form>
        </CardContent>
        <CardFooter className="flex-col gap-2">
          <Button type="submit" className="w-full">
            로그인
          </Button>
          <Button variant="outline" className="w-full">
            Google로 로그인
          </Button>
        </CardFooter>
      </Card>
    </div>
  )
}
```

</ComponentPreview>

`-mx-(--card-spacing)`과 함께 음수 여백을 사용하여 콘텐츠가 가장자리까지 표시되도록 하면서 카드 삽입과 정렬된 상태를 유지하세요. 가장자리까지 확장된 콘텐츠가 바닥글 위에 있을 때, `CardContent`에 `-mb-(--card-spacing)`을 사용하여 섹션 간격을 제거하세요.

## API 참고

### Card

`Card` 컴포넌트는 카드 콘텐츠의 루트 컨테이너입니다.

| Prop        | 타입                | 기본값      |
| ----------- | ------------------- | ----------- |
| `size`      | `"default" \| "sm"` | `"default"` |
| `className` | `string`            | -           |

### CardHeader

`CardHeader` 컴포넌트는 제목, 설명 및 선택적 액션에 사용됩니다.

| Prop        | 타입     | 기본값 |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### CardTitle

`CardTitle` 컴포넌트는 카드 제목에 사용됩니다.

| Prop        | 타입     | 기본값 |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### CardDescription

`CardDescription` 컴포넌트는 제목 아래의 도움말 텍스트에 사용됩니다.

| Prop        | 타입     | 기본값 |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### CardAction

`CardAction` 컴포넌트는 헤더의 오른쪽 위에 콘텐츠를 배치합니다 (예: 버튼 또는 배지).

| Prop        | 타입     | 기본값 |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### CardContent

`CardContent` 컴포넌트는 카드의 주요 본문에 사용됩니다.

| Prop        | 타입     | 기본값 |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### CardFooter

`CardFooter` 컴포넌트는 카드 하단의 액션과 보조 콘텐츠에 사용됩니다.

| Prop        | 타입     | 기본값 |
| ----------- | -------- | ------- |
| `className` | `string` | -       |
