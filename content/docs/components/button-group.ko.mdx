## 설치

```bash
bunx shadcn@latest add @ondo-ui/button-group
```

## 사용법

```tsx
import {
  ButtonGroup,
  ButtonGroupSeparator,
  ButtonGroupText,
} from "@/components/ui/button-group"
```

```tsx
<ButtonGroup>
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</ButtonGroup>
```

## Composition

`ButtonGroup`을 구성하려면 다음과 같이 조합하세요:

```text
ButtonGroup
├── Button or Input
├── ButtonGroupSeparator
└── ButtonGroupText
```

## 접근성

- `ButtonGroup` 컴포넌트는 `role` 속성이 `group`으로 설정되어 있습니다.
- `Tab`을 사용하여 그룹 내 버튼 간 탐색할 수 있습니다.
- 버튼 그룹에 레이블을 지정하려면 `aria-label` 또는 `aria-labelledby`를 사용하세요.

```tsx
<ButtonGroup aria-label="Button group">
  <Button>버튼 1</Button>
  <Button>버튼 2</Button>
</ButtonGroup>
```

## ButtonGroup vs ToggleGroup

- 작업을 수행하는 버튼들을 그룹화하려면 `ButtonGroup` 컴포넌트를 사용합니다.
- 상태를 토글하는 버튼들을 그룹화하려면 `ToggleGroup` 컴포넌트를 사용합니다.

        <IconPlus />

        <IconMinus />

### 중첩

`<ButtonGroup>` 컴포넌트를 중첩하여 간격이 있는 버튼 그룹을 만듭니다.

<ComponentPreview name="button-group-nested">

import { Input } from "@/components/ui/input"

  InputGroup,
  InputGroupAddon,
  InputGroupInput,
} from "@/components/ui/input-group"
import {
  Tooltip,
  TooltipContent,
  TooltipTrigger,
} from "@/components/ui/tooltip"

export default function ButtonGroupNested() {
  return (
    <ButtonGroup>
      <ButtonGroup>
        <Button variant="outline" size="icon">
          <IconPlus />
        </Button>
      </ButtonGroup>

        <InputGroup>
          <InputGroupInput placeholder="Send a message..." />
          <Tooltip>
            <TooltipTrigger render={<InputGroupAddon align="inline-end" />}>
              <IconActivity />
            </TooltipTrigger>

          </Tooltip>
        </InputGroup>
      </ButtonGroup>

}

### 구분선

`ButtonGroupSeparator` 컴포넌트는 그룹 내 버튼들을 시각적으로 구분합니다.

`outline` 변형의 버튼은 이미 테두리가 있으므로 구분선이 필요하지 않습니다. 다른 변형의 경우 시각적 계층 구조를 개선하기 위해 구분선을 권장합니다.

<ComponentPreview name="button-group-separator">

```tsx
import { Button } from "@/components/ui/button"
import {
  ButtonGroup,
  ButtonGroupSeparator as ButtonGroupSeparatorComponent,
} from "@/components/ui/button-group"

export default function ButtonGroupSeparator() {
  return (
    <ButtonGroup>
      <Button variant="secondary" size="sm">
        Copy
      </Button>
      <ButtonGroupSeparatorComponent />
      <Button variant="secondary" size="sm">
        Paste
      </Button>
    </ButtonGroup>
  )
}
```

</ComponentPreview>

  Tooltip,

        <Button variant="outline" size="icon">

              </TooltipTrigger>
              <TooltipContent>Voice Mode</TooltipContent>
            </Tooltip>
          </InputGroupAddon>
        </InputGroup>

```tsx
"use client"

import * as React from "react"
import { IconArrowRight } from "@tabler/icons-react"

import { Button } from "@/components/ui/button"
import { ButtonGroup } from "@/components/ui/button-group"
import { Input } from "@/components/ui/input"
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectTrigger,
} from "@/components/ui/select"

const CURRENCIES = [
  { label: "US Dollar", value: "$" },
  { label: "Euro", value: "€" },
  { label: "British Pound", value: "£" },
]

export default function ButtonGroupSelect() {
  const [currency, setCurrency] = React.useState("$")

  return (
    <ButtonGroup>
      <ButtonGroup>
        <Select
          items={CURRENCIES}
          value={currency}
          onValueChange={(value) => setCurrency(value as string)}
        >
          <SelectTrigger className="font-mono">{currency}</SelectTrigger>
          <SelectContent alignItemWithTrigger={false} align="start">
            <SelectGroup>
              {CURRENCIES.map((item) => (
                <SelectItem key={item.value} value={item.value}>
                  {item.value}{" "}
                  <span className="text-muted-foreground">{item.label}</span>
                </SelectItem>
              ))}
            </SelectGroup>
          </SelectContent>
        </Select>
        <Input placeholder="10.00" pattern="[0-9]*" />
      </ButtonGroup>
      <ButtonGroup>
        <Button aria-label="Send" size="icon" variant="outline">
          <IconArrowRight />
        </Button>
      </ButtonGroup>
    </ButtonGroup>
  )
}
```

## API 참고

### ButtonGroup

`ButtonGroup` 컴포넌트는 관련 버튼들을 일관된 스타일로 함께 묶는 컨테이너입니다.

| Prop          | Type                         | Default        |
| ------------- | ---------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |

```tsx
<ButtonGroup>
  <Button>버튼 1</Button>
  <Button>버튼 2</Button>
</ButtonGroup>
```

여러 버튼 그룹을 중첩하여 간격이 있는 복잡한 레이아웃을 만듭니다. 자세한 내용은 [중첩](#중첩) 예시를 참조하세요.

```tsx
<ButtonGroup>
  <ButtonGroup />
  <ButtonGroup />
</ButtonGroup>
```

### ButtonGroupSeparator

`ButtonGroupSeparator` 컴포넌트는 그룹 내 버튼들을 시각적으로 구분합니다.

| Prop          | Type                         | Default      |
| ------------- | ---------------------------- | ------------ |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` |

```tsx
<ButtonGroup>
  <Button>버튼 1</Button>
  <ButtonGroupSeparator />
  <Button>버튼 2</Button>
</ButtonGroup>
```

### ButtonGroupText

버튼 그룹 내에서 텍스트를 표시하려면 이 컴포넌트를 사용합니다.

| Prop      | Type      | Default |
| --------- | --------- | ------- |
| `asChild` | `boolean` | `false` |

```tsx
<ButtonGroup>
  <ButtonGroupText>Text</ButtonGroupText>
  <Button>버튼</Button>
</ButtonGroup>
```

`asChild` prop을 사용하여 라벨 같은 커스텀 컴포넌트를 텍스트로 렌더링할 수 있습니다.

```tsx
import { ButtonGroupText } from "@/components/ui/button-group"
import { Label } from "@/components/ui/label"

export default function ButtonGroupTextDemo() {
  return (
    <ButtonGroup>
      <ButtonGroupText asChild>
        <Label htmlFor="name">Text</Label>
      </ButtonGroupText>
      <Input placeholder="Type something here..." id="name" />
    </ButtonGroup>
  )
}
```
