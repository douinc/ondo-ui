## CLI 사용

<Steps>

### 프로젝트 만들기

```bash
bunx --bun @dou.so/ondo-ui@latest init -t start
```

monorepo라면 `--monorepo` 옵션을 추가하세요. 명령이 Ondo 테마와 `@ondo-ui` 레지스트리를 자동으로 설정합니다.

추가 컴포넌트는 다음처럼 설치합니다:

```bash
npx shadcn@latest add @ondo-ui/button
```

</Steps>

## 기존 프로젝트

<Steps>

### 프로젝트 만들기

새 프로젝트라면 TanStack CLI에서 TanStack Start와 React, 권장 기본값을 선택하세요:

```bash
npx @tanstack/cli@latest create
```

CLI가 Tailwind CSS와 `@/*` import alias를 설정합니다. shadcn add-on은 선택하지 않고 다음 단계에서 설정하세요.

### CLI 실행

```bash
npx shadcn@latest init
```

### Ondo registry 등록

```json title="components.json"
{
  "registries": {
    "@ondo-ui": "https://ui.ondo.dou.so/r/{name}.json"
  }
}
```

### 테마와 컴포넌트 추가

```bash
npx shadcn@latest add @ondo-ui/theme @ondo-ui/theme-provider
npx shadcn@latest add @ondo-ui/button
```

[테마 가이드](/docs/theming)에 따라 필요한 경우 `ThemeProvider`를 추가하세요.

### 컴포넌트 사용

```tsx
import { Button } from "@/components/ui/button"

export function Example() {
  return <Button>클릭</Button>
}
```

</Steps>
