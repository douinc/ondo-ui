## shadcn/create 사용

<Steps>

### 프리셋 만들기

[shadcn/create](https://ui.shadcn.com/create?template=vite)에서 프리셋을 만들고 아래 링크에서 설정을 시작하세요.

<Button asChild size="sm"><Link href="https://ui.shadcn.com/create?template=vite" target="_blank" rel="noopener noreferrer" className="mt-6 no-underline!">shadcn/create 열기</Link></Button>

### 프로젝트 만들기

```bash
npx shadcn@latest init --preset [CODE] --template vite
```

</Steps>

## 기존 프로젝트

<Steps>

### 프로젝트 만들기

```bash
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install
```

### Tailwind CSS 설정

```bash
npm install tailwindcss @tailwindcss/vite
```

`vite.config.ts`에 플러그인을 추가하고 `src/index.css`에 Tailwind를 import합니다:

```ts title="vite.config.ts"
import tailwindcss from "@tailwindcss/vite"

export default { plugins: [tailwindcss()] }
```

```css title="src/index.css"
@import "tailwindcss";
```

### Import Alias 설정

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": { "@/*": ["./src/*"] }
  }
}
```

### CLI 실행 및 registry 등록

```bash
npx shadcn@latest init
```

```json title="components.json"
{
  "registries": {
    "@ondo-ui": "https://ui.ondo.dou.so/r/{name}.json"
  }
}
```

### 테마와 컴포넌트 추가

```bash
npx shadcn@latest add @ondo-ui/theme @ondo-ui/theme-provider
npx shadcn@latest add @ondo-ui/button
```

[테마 가이드](/docs/theming)에 따라 `ThemeProvider`를 설정할 수 있습니다.

### 컴포넌트 사용

```tsx
import { Button } from "@/components/ui/button"

export default function Example() {
  return <Button>클릭</Button>
}
```

</Steps>
