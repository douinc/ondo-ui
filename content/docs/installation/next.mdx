## Use the CLI

<Steps>

### Create Project

Run the init command and follow the prompts to configure your Next.js project:

```bash
npx shadcn@latest init -t next
```

### Add Components

Ondo components are added after registering the Ondo registry in the existing-project steps below.

</Steps>

## Existing Project

<Steps>

### Create Project

If you need a new Next.js project, create one first. Otherwise, skip this step:

```bash
npx create-next-app@latest my-app
cd my-app
```

Use the recommended defaults, including TypeScript, Tailwind CSS, and the `@/*` import alias.

### Configure Import Aliases

If the alias is not already configured, add it to `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": { "@/*": ["./*"] }
  }
}
```

### Run the CLI

```bash
npx shadcn@latest init
```

### Register the Ondo Registry

Add the `@ondo-ui` namespace to `components.json`:

```json title="components.json"
{
  "registries": {
    "@ondo-ui": "https://ui.ondo.dou.so/r/{name}.json"
  }
}
```

### Add the Theme and a Component

```bash
npx shadcn@latest add @ondo-ui/theme @ondo-ui/theme-provider
npx shadcn@latest add @ondo-ui/button
```

`@ondo-ui/theme-provider` is optional when React dark-mode switching is not used. If installed, follow the [theming guide](/docs/theming) to add `ThemeProvider` to the application root.

### Use the Component

```tsx
import { Button } from "@/components/ui/button"

export default function Example() {
  return <Button>Click me</Button>
}
```

</Steps>
