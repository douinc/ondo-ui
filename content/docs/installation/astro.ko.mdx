## CLI 사용

<Steps>

### 프로젝트 만들기

```bash
npx ondo-ui@latest init -t astro
```

monorepo라면 `--monorepo` 옵션을 추가하세요.

명령이 Ondo 테마와 `@ondo-ui` 레지스트리를 자동으로 설정합니다. 추가 컴포넌트는 다음처럼 설치합니다:

```bash
npx shadcn@latest add @ondo-ui/button
```

</Steps>

## 기존 프로젝트

<Steps>

### 프로젝트 만들기

Tailwind CSS와 React integration을 함께 설정합니다:

```bash
npm create astro@latest astro-app -- --template with-tailwindcss --install --add react --git
```

### Import Alias 설정

`tsconfig.json`에 alias가 없다면 추가합니다:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": { "@/*": ["./src/*"] }
  }
}
```

### CLI 실행 및 registry 등록

```bash
npx shadcn@latest init
```

```json title="components.json"
{
  "registries": {
    "@ondo-ui": "https://ui.ondo.dou.so/r/{name}.json"
  }
}
```

### 테마와 컴포넌트 추가

```bash
npx shadcn@latest add @ondo-ui/theme @ondo-ui/theme-provider
npx shadcn@latest add @ondo-ui/button
```

[테마 가이드](/docs/theming)에 따라 `ThemeProvider`를 설정할 수 있습니다.

### 컴포넌트 사용

```astro
---
import { Button } from "@/components/ui/button"
---

<Button>클릭</Button>
```

</Steps>
