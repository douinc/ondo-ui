## Use the CLI

<Steps>

### Create Project

```bash
npx shadcn@latest init -t astro
```

For a monorepo, add `--monorepo` to the command.

### Add Components

Astro projects need the React integration before rendering Ondo React components. Register the Ondo namespace before adding them.

</Steps>

## Existing Project

<Steps>

### Create Project

If you need a new Astro project, use the Tailwind and React integrations:

```bash
npm create astro@latest astro-app -- --template with-tailwindcss --install --add react --git
```

### Configure Import Aliases

If `@/*` is not configured, add it to `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": { "@/*": ["./src/*"] }
  }
}
```

### Run the CLI

```bash
npx shadcn@latest init
```

### Register the Ondo Registry

```json title="components.json"
{
  "registries": {
    "@ondo-ui": "https://ui.ondo.dou.so/r/{name}.json"
  }
}
```

### Add the Theme and a Component

```bash
npx shadcn@latest add @ondo-ui/theme @ondo-ui/theme-provider
npx shadcn@latest add @ondo-ui/button
```

Follow the [theming guide](/docs/theming) when using `ThemeProvider`.

### Use the Component

```astro
---
import { Button } from "@/components/ui/button"
---

<Button>Click me</Button>
```

</Steps>
