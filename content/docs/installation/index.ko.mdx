## CLI 사용

터미널에서 Ondo CLI로 새 프로젝트를 만들고 레지스트리와 테마를 함께 설정합니다. 전체 명령은 [CLI 레퍼런스](/docs/cli)에서 확인하세요:

```bash title="터미널"
bunx --bun @dou.so/ondo-ui@latest init -t [framework]
```

지원 템플릿은 `next`, `vite`, `start`, `react-router`, `astro`입니다.

Laravel은 먼저 `laravel new`로 앱을 만든 뒤 앱 디렉터리에서 `bunx --bun @dou.so/ondo-ui@latest init -t laravel`을 실행하세요.

## 사전 준비

ondo-ui 컴포넌트는 [shadcn CLI](https://ui.shadcn.com/docs/installation)로 설정된 프로젝트를 전제로 합니다 — Tailwind CSS v4, `components.json`, `cn()` 유틸리티. 새 프로젝트라면 위에서 framework를 선택해 먼저 프로젝트를 초기화하세요.

## 테마 추가

Ondo CLI가 framework에 맞는 테마를 자동으로 설치하고 `components.json`에 `@ondo-ui` 네임스페이스를 추가합니다.

## 컴포넌트 추가

Ondo CLI로 Components와 Compositions를 그룹별 메뉴에서 선택할 수 있습니다:

```bash
bunx --bun @dou.so/ondo-ui add
```

이름을 직접 지정하거나 변경 사항을 미리 보고, 메뉴에 표시되는 모든 항목을
설치할 수도 있습니다:

```bash
bunx --bun @dou.so/ondo-ui add button empty-view
bunx --bun @dou.so/ondo-ui add button --dry-run
bunx --bun @dou.so/ondo-ui add --all
bunx --bun @dou.so/ondo-ui add -a
```

`init`은 템플릿의 기본 컴포넌트(예: 스타터 `button.tsx`)를 `@ondo-ui`
버전으로 자동 교체합니다 — 둘이 섞이면 타입 체크가 깨지기 때문입니다. 구버전
CLI로 초기화한 프로젝트에서 기본 컴포넌트 관련 타입 에러가 나면 한 번만
`--overwrite`로 재설치하세요:

```bash
bunx --bun @dou.so/ondo-ui add button --overwrite
```

`empty-view`, `number-badge` 같은 Compositions는 일반 registry UI
컴포넌트와 별도 그룹으로 표시됩니다. `utils` 같은 의존성은 자동으로 해결됩니다.

공식 shadcn 명령어를 직접 사용하려면 다음과 같이 실행하세요:

```bash
bunx shadcn@latest add @ondo-ui/button
```

그다음 프로젝트에서 import 하세요:

```tsx
import { Button } from "@/components/ui/button"

export default function Example() {
  return <Button>클릭</Button>
}
```

Ondo CLI는 shadcn의 전체 명령을 지원합니다: `search`(`list` 별칭), `view`,
`docs`, `diff`(`add --diff`로 변환), `apply`, `info`, `migrate`, `eject`, `mcp`,
`preset`, `build`, `registry`. 다른 프로젝트를 대상으로 하려면 `--cwd <path>`를
사용하세요. 전체 명령과 예시는 [CLI 레퍼런스](/docs/cli)에서 확인할 수
있습니다.
