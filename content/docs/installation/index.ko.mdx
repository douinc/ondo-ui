## CLI 사용

터미널에서 CLI로 새 프로젝트를 바로 만들 수 있습니다:

```bash title="터미널"
npx shadcn@latest init -t [framework]
```

지원 템플릿은 `next`, `vite`, `start`, `react-router`, `astro`입니다.

Laravel은 먼저 `laravel new`로 앱을 만든 뒤 `npx shadcn@latest init`을 실행하세요.

## 사전 준비

ondo-ui 컴포넌트는 [shadcn CLI](https://ui.shadcn.com/docs/installation)로 설정된 프로젝트를 전제로 합니다 — Tailwind CSS v4, `components.json`, `cn()` 유틸리티. 새 프로젝트라면 위에서 framework를 선택해 먼저 프로젝트를 초기화하세요.

## 레지스트리 등록

`components.json`의 `registries` 필드에 `@ondo-ui` 네임스페이스를 추가합니다:

```json title="components.json"
{
  "registries": {
    "@ondo-ui": "https://ui.ondo.dou.so/r/{name}.json"
  }
}
```

## 테마 추가

먼저 ondo 테마를 설치하세요 — Pretendard·Monaspace Neon 폰트와 기본 CSS 변수가 함께 들어옵니다:

```bash
bunx shadcn@latest add @ondo-ui/theme @ondo-ui/theme-provider
```

## 컴포넌트 추가

이름으로 원하는 컴포넌트를 추가합니다. `utils` 같은 의존성은 자동으로 해결됩니다:

```bash
bunx shadcn@latest add @ondo-ui/button
```

그다음 프로젝트에서 import 하세요:

```tsx
import { Button } from "@/components/ui/button"

export default function Example() {
  return <Button>클릭</Button>
}
```
