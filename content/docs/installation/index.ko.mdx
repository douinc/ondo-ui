## CLI 사용

터미널에서 Ondo CLI로 새 프로젝트를 만들고 레지스트리와 테마를 함께 설정합니다:

```bash title="터미널"
npx @dou.so/ondo-ui@latest init -t [framework]
```

지원 템플릿은 `next`, `vite`, `start`, `react-router`, `astro`입니다.

Laravel은 먼저 `laravel new`로 앱을 만든 뒤 앱 디렉터리에서 `npx @dou.so/ondo-ui@latest init -t laravel`을 실행하세요.

## 사전 준비

ondo-ui 컴포넌트는 [shadcn CLI](https://ui.shadcn.com/docs/installation)로 설정된 프로젝트를 전제로 합니다 — Tailwind CSS v4, `components.json`, `cn()` 유틸리티. 새 프로젝트라면 위에서 framework를 선택해 먼저 프로젝트를 초기화하세요.

## 테마 추가

Ondo CLI가 framework에 맞는 테마를 자동으로 설치하고 `components.json`에 `@ondo-ui` 네임스페이스를 추가합니다.

## 컴포넌트 추가

이름으로 원하는 컴포넌트를 추가합니다. `utils` 같은 의존성은 자동으로 해결됩니다:

```bash
bunx shadcn@latest add @ondo-ui/button
```

그다음 프로젝트에서 import 하세요:

```tsx
import { Button } from "@/components/ui/button"

export default function Example() {
  return <Button>클릭</Button>
}
```
