## CLI 사용

<Steps>

### 프로젝트 만들기

```bash
bunx --bun @dou.so/ondo-ui@latest init -t react-router
```

monorepo라면 `--monorepo` 옵션을 추가하세요. 명령이 Ondo 테마와 `@ondo-ui` 레지스트리를 자동으로 설정합니다.

추가 컴포넌트는 다음처럼 설치합니다:

```bash
npx shadcn@latest add @ondo-ui/button
```

</Steps>

## 기존 프로젝트

<Steps>

### 프로젝트 만들기

```bash
npm create react-router@latest
```

스타터가 Tailwind CSS와 기본 `~/*` import alias를 설정합니다.

### CLI 실행

```bash
npx shadcn@latest init
```

### Ondo registry 등록

```json title="components.json"
{
  "registries": {
    "@ondo-ui": "https://ui.ondo.dou.so/r/{name}.json"
  }
}
```

### 테마와 컴포넌트 추가

```bash
npx shadcn@latest add @ondo-ui/theme @ondo-ui/theme-provider
npx shadcn@latest add @ondo-ui/button
```

[테마 가이드](/docs/theming)에서 `ThemeProvider` 설정을 확인하세요.

### 컴포넌트 사용

```tsx
import { Button } from "~/components/ui/button"

export default function Home() {
  return <Button>클릭</Button>
}
```

</Steps>
