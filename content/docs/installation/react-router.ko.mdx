## 새 프로젝트 만들기

shadcn CLI로 React Router 프로젝트를 만드세요:

```bash
bunx shadcn@latest init -t react-router
```

## 기존 프로젝트

이미 React Router 프로젝트가 있다면 `components.json`이 없는 경우 먼저 `bunx shadcn@latest init`을 실행하세요.

## 레지스트리 등록

`components.json`의 `registries` 필드에 `@ondo-ui` 네임스페이스를 추가합니다:

```json title="components.json"
{
  "registries": {
    "@ondo-ui": "https://ui.ondo.dou.so/r/{name}.json"
  }
}
```

## 테마 추가

Ondo 테마를 설치하세요. Pretendard, Monaspace Neon 폰트와 기본 CSS 변수를 추가합니다:

```bash
bunx shadcn@latest add @ondo-ui/theme @ondo-ui/theme-provider
```

React 다크 모드 전환을 사용하지 않는다면 `@ondo-ui/theme-provider`는 선택 사항입니다. 설치했다면 [테마 가이드](/docs/theming)에 따라 애플리케이션 루트에 `ThemeProvider`를 추가하세요.

## 컴포넌트 추가

```bash
bunx shadcn@latest add @ondo-ui/button
```

`utils` 같은 의존성은 자동으로 해결됩니다.

## 컴포넌트 사용

```tsx
import { Button } from "@/components/ui/button"

export default function Example() {
  return <Button>클릭</Button>
}
```
