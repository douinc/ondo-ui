## Use the CLI

Use the CLI to scaffold a new project directly from the terminal:

```bash title="Terminal"
npx shadcn@latest init -t [framework]
```

Supported templates: `next`, `vite`, `start`, `react-router`, and `astro`.

For Laravel, create the app first with `laravel new`, then run `npx shadcn@latest init`.

## Prerequisites

ondo-ui components assume a project set up with the [shadcn CLI](https://ui.shadcn.com/docs/installation) — Tailwind CSS v4, a `components.json`, and the `cn()` utility. If you are starting fresh, choose a framework above to initialize the project first.

## Register the registry

Add the `@ondo-ui` namespace to the `registries` field of your `components.json`:

```json title="components.json"
{
  "registries": {
    "@ondo-ui": "https://ui.ondo.dou.so/r/{name}.json"
  }
}
```

## Add the theme

Install the ondo theme first — it brings the Pretendard and Monaspace Neon fonts plus the base CSS variables:

```bash
bunx shadcn@latest add @ondo-ui/theme @ondo-ui/theme-provider
```

## Add components

Add any component by name. Dependencies such as `utils` are resolved automatically:

```bash
bunx shadcn@latest add @ondo-ui/button
```

Then import it from your project:

```tsx
import { Button } from "@/components/ui/button"

export default function Example() {
  return <Button>Click me</Button>
}
```
