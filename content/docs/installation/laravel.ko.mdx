shadcn CLI는 Laravel 앱을 직접 생성하지 않습니다. React starter kit을 선택해 Laravel 앱을 만든 뒤 Ondo UI를 설정하세요.

<Steps>

### 프로젝트 만들기

```bash
laravel new my-app
cd my-app
```

프롬프트에서 React starter kit을 선택하세요. 이미 React와 Inertia가 설정된 앱이라면 이 단계를 건너뜁니다.

</Steps>

## CLI 사용

<Steps>

### CLI 실행

```bash
npx @dou.so/ondo-ui@latest init -t laravel
```

명령이 Laravel frontend 경로를 유지하면서 Ondo 테마와 provider를 설치하고 `@ondo-ui` 레지스트리를 설정합니다.

</Steps>

## 기존 프로젝트

<Steps>

### Ondo registry 등록

```json title="components.json"
{
  "registries": {
    "@ondo-ui": "https://ui.ondo.dou.so/r/{name}.json"
  }
}
```

### 테마와 컴포넌트 추가

```bash
npx shadcn@latest add @ondo-ui/theme @ondo-ui/theme-provider
npx shadcn@latest add @ondo-ui/button
```

[테마 가이드](/docs/theming)에 따라 `ThemeProvider`를 설정하세요.

### 컴포넌트 사용

```tsx
import { Button } from "@/components/ui/button"

export default function Example() {
  return <Button>클릭</Button>
}
```

</Steps>
