## Create a new project

For a project that does not use one of the supported templates, start with your framework's normal project setup and then initialize shadcn:

```bash
bunx shadcn@latest init
```

Your project needs Tailwind CSS v4, a `components.json` file, and the shadcn `cn()` utility.

## Existing Project

Run the initialization command from the project root if shadcn has not been configured yet.

## Register the registry

Add the `@ondo-ui` namespace to the `registries` field of your `components.json`:

```json title="components.json"
{
  "registries": {
    "@ondo-ui": "https://ui.ondo.dou.so/r/{name}.json"
  }
}
```

## Add the theme

Install the Ondo theme. It adds Pretendard, Monaspace Neon, and the base CSS variables:

```bash
bunx shadcn@latest add @ondo-ui/theme @ondo-ui/theme-provider
```

`@ondo-ui/theme-provider` is optional when your project does not use React dark-mode switching. If it is installed, follow the [theming guide](/docs/theming) to add `ThemeProvider` to the application root.

## Add a component

```bash
bunx shadcn@latest add @ondo-ui/button
```

Dependencies such as `utils` are resolved automatically.

## Use the component

```tsx
import { Button } from "@/components/ui/button"

export default function Example() {
  return <Button>Click me</Button>
}
```
