**v1.8.5**

- Ondo UI 컴포넌트, 데모, 문서 사이트, Design Inspector가
  [`cn`](https://www.npmjs.com/package/cn) 패키지에서 `cn`을 직접
  import합니다.
- `cn`을 쓰는 모든 레지스트리 항목이 npm dependency로 이를 선언하므로,
  `shadcn add @ondo-ui/<component>` 실행 시 자동으로 설치됩니다.
- `@ondo-ui/utils` 레지스트리 항목과 로컬 `lib/utils.ts` helper를
  제거했습니다. 로컬 `@/lib/utils` import는 `import { cn } from "cn"`으로
  바꾸세요.
