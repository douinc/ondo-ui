**v1.4.0**

- Add an interactive `add` menu for Ondo Components and Compositions.
- Add direct item installation with `add <name>` and bulk installation with
  `add --all`.
- Add Ondo-aware support for the shadcn commands used to search, view, apply,
  migrate, eject, configure MCP, and manage registries.
- Add CLI documentation for project setup, registry installation, and command
  usage.
