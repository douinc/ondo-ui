**v1.4.0**

- Ondo Components와 Compositions를 선택하는 대화형 `add` 메뉴를
  추가했습니다.
- `add <name>` 직접 설치와 `add --all` 일괄 설치를 추가했습니다.
- shadcn의 검색, 조회, 적용, 마이그레이션, eject, MCP 설정, 레지스트리
  관리 명령을 Ondo CLI에서 사용할 수 있게 했습니다.
- 프로젝트 설정, 레지스트리 설치, CLI 명령 사용법 문서를 추가했습니다.
