**v1.5.0**

- `@dou.so/design-inspector` npm 패키지를 추가했습니다. 모바일·태블릿·FHD·QHD
  뷰포트에서 마운트된 Components와 Compositions를 점검하는 개발 전용
  같은 origin 오버레이로, 컴포넌트 레이어, 비교 모드, 키보드 단축키,
  페이지 탐색, `DesktopWindow` 스크린샷을 제공합니다. 레지스트리 설치가
  아니라 패키지 import로 사용하며, 인스펙터 요소에만 스코프된 사전 컴파일
  스타일시트를 함께 제공합니다.
- 테마 처리를 호스트 애플리케이션에 위임했습니다. 시스템 테마는
  `prefers-color-scheme`으로 계산하고 색상 모드는 오버레이에만 스코프하며,
  `light`/`dark` 클래스와 다른 테마 방식을 쓰는 애플리케이션을 위해
  `onThemeChange`와 `applyPreviewTheme`를 제공합니다.
- 인스펙터가 인스턴스와 표현 속성을 식별할 수 있도록 Frame 루트에
  `data-variant`를, LiveWaveform, NumberCount, EmptyView, NumberBadge 루트에
  `data-slot` 마커를 추가했습니다.
