**v0.1.0**

ondo-ui에 **Compositions** 계층을 추가했습니다 — 컴포넌트와 블록 사이의 계층입니다.

- **Components**: 직접 조합하는 저수준 프리미티브.
- **Compositions**: 프리미티브를 집중된 props API로 미리 조합한 컴포넌트.
- **Blocks**: 페이지 단위 섹션(준비 중).

## EmptyView

첫 조합 컴포넌트는 [`EmptyView`](/docs/compositions/empty-view)입니다 — `Empty`와 `Button`으로 미리 조합한 빈 상태 컴포넌트로, 콘텐츠만 넘기면 됩니다:

```bash
bunx shadcn@latest add @ondo-ui/empty-view
```

새 [Compositions](/compositions) 페이지에서 모아 볼 수 있으며, 상단 내비와 docs 사이드바에 추가됐습니다.
