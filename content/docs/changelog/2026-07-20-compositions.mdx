**v0.1.0**

We've added a new **Compositions** layer to ondo-ui — the space between components and blocks.

- **Components** are the low-level primitives you compose yourself.
- **Compositions** are ready-made components that combine primitives behind a focused props API.
- **Blocks** are full page sections (coming soon).

## EmptyView

The first composition is [`EmptyView`](/docs/compositions/empty-view) — a ready-made empty state composed from `Empty` and `Button`. Pass your content and go:

```bash
bunx shadcn@latest add @ondo-ui/empty-view
```

Browse compositions on the new [Compositions](/compositions) page, now in the top nav and the docs sidebar.
